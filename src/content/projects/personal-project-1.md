## Overview

A personal project built to explore agentic developer workflows. It connects language models with terminal environments and GitHub automation.

### Key Features
- Dynamic context-aware agent coordination
- Streamlined terminal and workspace integration
- Fully customizable workflow configurations

### Technologies Used
- **Frontend & UI:** Astro, Tailwind CSS
- **Core Engine:** TypeScript, Node.js
- **APIs:** GitHub REST & GraphQL APIs
