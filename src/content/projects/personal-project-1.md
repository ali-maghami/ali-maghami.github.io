## Project Overview

Led architecture and deployment of a sophisticated automated vision system for railcar loading operations, integrating 40+ heterogeneous cameras, stereo pairs, laser profilers, and specialized sensors for real-time localization, measurement, and operational decision support.

## Key Achievements

- **System Architecture:** Designed containerized vision and AI pipeline deployed across Linux edge systems with Azure cloud backend
- **Real-Time Processing:** Implemented 2D/3D localization and measurement algorithms for high-throughput railcar inspection
- **Scalability:** Managed heterogeneous sensor fusion (40+ cameras, laser profilers) with deterministic latency requirements
- **Deployment Excellence:** Established CI/CD pipelines using GitHub Actions for automated builds, testing, and controlled deployments
- **Impact:** Enabled precision logistics operations with measurable uptime and accuracy improvements

## Technologies

- **Vision Stack:** 2D/3D imaging, stereo vision, laser profiling, point-cloud processing, metrology
- **Software:** Python, C++, OpenCV, Open3D
- **Cloud & Edge:** Azure IoT Hub, Azure Blob Storage, Container Registry, Docker, Linux
- **CI/CD:** GitHub Actions, automated testing and deployment pipelines
