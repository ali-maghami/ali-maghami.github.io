## Overview

Architected and deployed a sophisticated vision system for railcar loading operations, integrating 40+ heterogeneous cameras, stereo pairs, and laser profilers for real-time localization and measurement.

## Contributions

- Designed containerized vision pipeline deployed across Linux edge systems with Azure cloud backend
- Implemented 2D/3D localization and measurement algorithms for high-throughput inspection
- Managed CI/CD pipelines using GitHub Actions for automated builds and deployments
- Coordinated with cross-functional teams spanning automation, electrical, and mechanical engineering

## Technologies

Computer Vision, 3D Imaging, Python, OpenCV, Open3D, Azure IoT Hub, Docker, Linux
